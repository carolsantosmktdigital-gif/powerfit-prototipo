# Power Fit Studio — Protótipo navegável

Protótipo estático para demonstração aos sócios.

## Publicar no GitHub Pages

1. Crie um repositório novo, por exemplo `powerfit-prototipo`.
2. Copie os arquivos desta pasta para o repositório.
3. Faça o commit e o push pelo GitHub Desktop.
4. No GitHub, abra **Settings > Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Branch: `main` e pasta: `/ (root)`.
7. Salve e aguarde a publicação.

O protótipo não usa Node, npm ou dependências externas. O `index.html` pode ser publicado diretamente pelo GitHub Pages.

## Observação

É uma demonstração navegável, com dados fictícios. Não é o sistema de produção e não contém banco de dados real, autenticação real ou integração real com Wellhub.
